# apprentice-updates

Sparkle auto-update feed for the Apprentice macOS app.

- `appcast.xml` — the Sparkle feed (`SUFeedURL` points here via raw.githubusercontent.com).
- `.zip` update bundles are attached to GitHub Releases (tag `vX.Y.Z`).

The app's `SUFeedURL` is:
`https://raw.githubusercontent.com/Reppin123/apprentice-updates/main/appcast.xml`
